## 0. 一句话结论

V1 的 AI 层是一套**"可选增强、全程可降级"**的旁路系统：

* 任一条件不满足（AI 关闭 / 无密钥 / 高峰时段 / 预算熔断）→ 全部退化为**规则**，功能不消失、不抛异常（`AI/AI调度器.py:426-452`、`AI/AI智能助手.py:433-461`）。
* AI 有三种执行后端，优先级固定为 **本地模型（ollama）→ 云端 OpenAI 兼容网关 → 规则**。
* **AI 侧对播放器的代码依赖 ≈ 0**：`AI/字幕助手.py`、`AI/播放顾问.py` 既不 import `vlc`、也不 import Qt、更不 import 播放核心；耦合是**反向的**（播放核心用鸭子类型调顾问）＋集中在 `界面/AI播放面板.py` 与 `界面/播放页面.py`（见 §6）。
* 最大的整合风险不在 AI 代码，而在**进程与磁盘**：ollama 与 Whisper 工作进程都没有在退出时被回收（见 §8.1）。
