### 2.4 ⚠️ 已发现的接口缺口（影响整合）

1. **引擎不保存请求头**：`播放直链(地址, 请求头)` 只把请求头交给 `打开()` 拼 AVIO 选项，
   全文件没有 `self._请求头` 赋值（grep 无命中）。而 `主窗口._出预览图` 读的是
   `getattr(self.引擎, "_请求头", {})`（`主窗口.py:426`）→ **恒为 `{}`**。
   结论：网络直链的进度条缩略图拿不到 UA/Referer/Cookie，需要鉴权的 CDN 会取图失败
   （本地文件/公开直链不受影响）。**未确认**在真机网盘直链上是否必然失败，机制上确定会丢头。
2. 引擎无信号、无回调（除 `日志回调`）→ 任何"事件驱动"的新架构都要加一层适配或继续轮询。
3. `引擎.统计` 是可变 dataclass，界面直接读；多页共享时要注意"谁在写"。

### 5.3 读写模式总结

1. **没有统一入口**：路径各自算、JSON 各自解析，没有 schema 校验、没有迁移框架
   （只有 `资料库.db` 有 `_迁移`；`播放记录.json` 有 `"版本": 1`，其它文件没有版本号）。
2. **读全吞异常**（坏文件 = 当空的），写多为 `.tmp` + `os.replace`
   （`记录.py:95-97`、`光鸭.py:92-94`）；`主窗口.存弹幕设置` 是直接 `write_text`（非原子，`:662`）。
3. **凭据文件**：`令牌_光鸭.json`（chmod 600）、`刮削.json`（本机 600）、`弹幕源.json`（600）。
   审计时不要把内容抄进报告/日志。
4. **两处多写者风险**：`数据/弹幕设置.json` 会被"弹幕设置面板"（经主窗口整写）和未来"敏感词页"
   同时改；`主窗口.存弹幕设置 :655` 是整体覆盖，后写者覆盖先写者（没有 merge）。
5. `数据/截图` 的相对路径在"从别的 cwd 启动"时会落到别处（`启动.sh` 会 `cd` 到项目根，
   所以正常启动没问题；被当库 import 时是隐患）。

- 断言：违规行为空。语义 = **自研内核不许靠 ffmpeg/ffprobe/vlc 命令行**（libav* 只能 ctypes 直连）。

**③ `test_自带解释器是V2自己的`（`:61-78`）**
- `运行环境/venv/pyvenv.cfg` 必须存在。
- venv 里必须有 site-packages（Linux `lib/python3*/site-packages` 或 Windows `Lib/site-packages`）。
- `site-packages.resolve()` 必须在**项目根**之下（**判据是"在项目里"，不是目录名**，
  注释说明 CI 检出目录叫 `wangpan-manager-v2`）。
- `site-packages/PySide6` 必须是目录。

**④ `test_只有标准库与PySide6`（`:80-126`）**
- 对同一批文件 `ast.parse`，遍历 `ast.Import` / `ast.ImportFrom`：
  - `Import`：取顶层名，必须命中允许前缀 `("PySide6","shiboken6","tests","wangpan","构建","工具")`
    或一长串标准库白名单（`:92-105`，含 `os/sys/time/ctypes/queue/threading/pathlib/typing/
    dataclasses/unittest/re/tempfile/shutil/subprocess/argparse/importlib/ast/json/struct/math/
    collections/functools/itertools/logging/signal/hashlib/zipfile/urllib/socket/xml/sqlite3/
    concurrent/base64/io/http/socketserver/datetime/enum/abc/contextlib/traceback/warnings/
    random/unicodedata/difflib/statistics/glob/shlex/csv/ssl` …）。
  - `ImportFrom`：**只检查 `level == 0` 的绝对导入**（`:107-109` 明确相对导入 `from ..player import …`
    本来就该允许）；根名同样要在白名单里。
- 断言：`sorted(set(违规)) == []`，失败信息 `文件名: import 名字` / `文件名: from 模块`。
- 含义：**第三方依赖只允许 PySide6（+ shiboken6）**；libav* 是系统库走 `ctypes`，不是 Python 依赖
  （`pyproject.toml:6` 的 `dependencies = ["PySide6>=6.6"]` 也是这个意思）。

**整合提示**：任何新页面/新模块若 `import requests / numpy / aiohttp / PySide6.QtXxx`（Qt 子模块没问题）
之外的第三方，会直接踩红这条；`import 构建`、`import 工具` 反而在白名单里（前缀允许）。

## 7. 可扩展点与改造清单

### 7.1 会被新页面挡路的地方（逐条，含位置）

1. **标签页写死 3 个、顺序固定**：`标签.addTab` 只在 `:172`、`:173`、`:187` 三处；
   播放页建在 `:64-68`。→ 插入 6 个新页必须改成"注册式"。
2. **`setCurrentIndex(0)` 硬编码指播放页**：`:296`、`:814`。
   一旦在播放页前面插页（如"网盘管理"作为主页），"播完直链跳回播放页"就会跳到新页。
3. **播放页不是成员变量**（局部 `播放页 :64`）→ 其它页面/外部拿不到它，也无法"切到播放页并给它传参"。
4. **主窗口 `new` 了所有共享对象**（`:45-49`、`:168-169`、`179-181`），没有共享层引用；
   `传输引擎` 藏在 `网盘页.传输`（`网盘页.py:33`）里，主窗口没保存 → 新"传输页"想共用调度器
   必须显式把引擎抽出来注入（`网盘页` 构造已支持传入 `传输引擎`，`:29`）。
5. **`退出前收尾()` 是硬编码清单 + 顺序敏感 + 15s 阻塞等待**（`:932-976`）。
   任何"有后台线程/有连接"的新页（AI、日志、传输）若不加进去，就会复现真机踩过的
   `QThread: Destroyed while thread is still running` → 进程 abort（`tests/test_海报墙关窗.py` 钉的就是它）。
6. **媒体库"可缺省"约定**（`try/except :175-191` + 到处 `getattr(..., None)`）：
   新页要么沿用这个降级风格，要么明确失败退出；混用会出现"一半页面没有库"的中间态。
7. **没有应用级事件总线**：主窗口自身零信号，跨页只能"子页信号 → 主窗口槽"一对一接线
   （§1.4）。"敏感词页改规则 → 播放页弹幕立刻生效"这类跨页联动目前没有通道。
8. **日志没有出口**：`_写日志` 只 append 到 `self._日志行` 并截断到 200 行（`:859-861`），
   不落盘、无级别、无订阅。所有 UI 反馈都挤在 `提示()`（状态栏 8s 临时消息）里。
   "日志页"需要新增日志总线 + 落盘。
9. **弹幕过滤规则被两处写**：`过滤规则/过滤器`（`danmaku/过滤.py`）+ 主窗口整体覆盖式保存
   （`:655-667`）。“敏感词页"接同一份文件时要么复用它、要么先做 merge，否则互相覆盖。
10. **配置无统一模块**（§5.1）：新页要存配置就得各自写 `数据/xxx.json`，
    或先补一个纯标准库的 `wangpan/配置.py`（不能引第三方，见 §6.3④）。
11. **缩略图请求头缺口**（§2.4）：播放页 + 网盘直链组合下，进度条预览会丢 UA/Cookie/Referer。
12. **`数据/截图` 相对路径**（`:818`）：非 `cd` 到项目根启动时会写错目录。
13. **传输任务不持久化**（§4.3）：做"传输页/下载管理"若要求重启保留，需要新增任务存储
    （现有 `任务` 是 dataclass + 事件，没有序列化）。
14. **`工厂.py` 用 if/elif 而不是类型注册表**（§4.2）：新增网盘类型必须动这个文件。

### 7.2 插页方案建议（改动最小、与现有约定一致）

**A. 骨架改造（约 20 行，先做）**
- 把播放页提升为 `self.播放页`，并记 `self.播放页序号 = self.标签.addTab(self.播放页, "▶ 播放")`；
- 加一个统一入口：`def 加页(self, 标题: str, 控件: QWidget) -> int`（内部 `标签.addTab` + 登记到
  `self.页表` + 登记到 `self._要关的页面`）；
- 用 `self.标签.setCurrentIndex(self.播放页序号)` 替换 `:296`、`:814` 的硬编码 `0`。

**B. 共享对象注入（不改现有调用方）**
- `self.传输 = self.网盘页.传输`（主窗口 `:169` 之后一行），新传输页 `传输页(self.传输, 父=None)`；
- 同理把 `资料库/图片缓存/注册表/引擎/弹幕/记录本` 作为构造参数传给需要的新页
  （现在它们是主窗口属性，直接传即可，不需要容器）。

**C. 新页面的统一约定（写进整合规范，便于评审）**
1. 构造函数只接收注入的共享对象 + `父=None`（不自己 `new` 引擎/库/缓存）；
2. 提供幂等 `关闭()`，并在主窗口登记（`退出前收尾` 改为遍历 `self._要关的页面` 逐个 `关闭()，
   再按现状顺序收尾引擎/刮削线程/资料库`）；
3. 跨页通信只发自己的 `Signal`，由主窗口接线（不要页与页互相 import 引用）；
4. **只能用 PySide6 + 标准库**（`tests/test_独立性.py` ④ 的 AST 白名单）；
5. 配置/数据落 `数据/` 下、用 `Path(__file__).resolve().parents[N]` 锚定，读吞异常、
   写用 `.tmp` + `os.replace`；若新增多个配置文件，建议同时补 `wangpan/配置.py` 收口。

**D. 播放页保持"自研内核"不动**
- 播放相关逻辑可暂时留在主窗口（现状），只新增页面不触碰 §3 的链路；
- 第二步（可选）：把 `打开/播放直链/续播/字幕/章节/预览/弹幕装载/截图` 抽成 `播放会话(QObject)`，
  以信号对外；但这是**行为等价重构**，会碰到 §6.5 的测试依赖（`_刷新`、`统计标签`），
  建议单独一轮并保留这些名字作为薄转发。

**E. 需要同时补的基础设施（若目标页面确实需要）**
- 日志总线（`日志页`）：给 `_写日志` 加订阅 + 落盘（`数据/日志/`）；
- 传输任务持久化（`传输页`）：`任务` → JSON/表，启动时恢复 `等待` 态；
- 统一配置模块（`设置页`）：`wangpan/配置.py`（纯标准库）；
- 敏感词：复用 `danmaku/过滤.py` 的 `过滤规则` + `数据/弹幕设置.json`，或独立成
  `数据/敏感词.json` 并让弹幕控制器从它装载（需在 `主窗口.配置变了 :686` 处统一写盘）。
