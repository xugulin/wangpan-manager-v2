# V2 × V1 整合方案（用户需求 → 架构决策 → 分工）

> 需求原文：**以本工作区（`网盘管理_V2`）的项目为主**，套用 `../网盘管理`（下称 V1）的
> **GUI**、**网盘管理功能**、**AI 的全部功能**；**播放页与播放器用 V2 的**（自研 libav 内核），
> 并做适当的整合优化。

---

## 一、结论：合并后的形态

**一个应用**：仓库仍是 V2（入口 `启动.py`、内核 `wangpan/`），
主窗口采用 **V1 的 GUI 骨架**（顶栏网盘导航 + 左侧功能栏 + `QStackedWidget` + 10 套主题），
播放页与播放器 **换成 V2 的自研内核**。

```
启动.py（合并入口：GC 策略 + 自举 + 控制台 + 应用名/桌面名）
 ├─ v8_3/                 ← V1 功能层（原样并入，作为本仓库的一部分）
 │   ├─ 界面/             ← GUI：主窗口 / 主题管理器 / 控件样式 / 各页面 / 对话框
 │   │   ├─ 播放页面.py    ← ★重写：V1 的公开契约 + V2 内核（不再是 VLC）
 │   │   └─ 播放器窗口.py  ← ★重写：独立窗口，共享同一个 V2 播放会话
 │   ├─ AI/               ← 全部 AI（助手/调度器/字幕助手/播放顾问/本地模型/模型市场/价格/时段预算/学习库）
 │   ├─ 核心/ 桥/ 敏感词/   ← 网盘管理：适配器契约 + 子进程桥 + 传输引擎 + 任务库 + 敏感词
 │   └─ 播放/             ← ★裁剪：只留 语音识别（ASR）、媒体信息；VLC 栈删除
 ├─ wangpan/              ← V2 内核（保留）
 │   ├─ player/ ffmpeg/ subtitle/ danmaku/ scrape/ pan/ transfer/
 │   └─ ui/
 │       ├─ 播放会话.py    ← ★新增：V2 引擎 → V1 会话接口的适配层
 │       ├─ 播放页.py      ← ★新增：内核级播放页（视频控件+控制条+弹幕+字幕+预览）
 │       ├─ 媒体库页.py    ← ★新增：把海报墙/详情页/待确认包成 V1 风格的一页
 │       └─ 主窗口.py      ← 保留：纯内核壳（`启动.py --纯播放`，回归用）
 └─ 适配器/               ← V1 的三家网盘适配器项目（百度/夸克/光鸭）
```

**依赖方向单一**：`v8_3.* → wangpan.*`（功能层用内核）。
`wangpan.*` 不 import `v8_3`（保住 V2 内核可独立运行与回归）。

## 二、关键决策与理由

| # | 决策 | 理由 |
|---|---|---|
| D1 | **`v8_3/` 原样放在仓库根，不改包名** | V1 内部 47k 行几乎全是包内相对导入，且有 5 处绝对导入 `from v8_3.…`、子进程 `cwd=v8_3/桥`、`parents[2]` 项目根解析。改名要动几十处且风险高、收益为零。文档里明确它是"V1 功能层"。 |
| D2 | **用 V1 的 `主窗口` 当合并后的主窗口** | 需求说"套用 V1 的 GUI"。V1 的 6 个业务页（网盘/传输/敏感词/AI/日志/设置）都是按 `(主窗口, 父=None)` + `主窗口.动作/配置/AI运行时` 这套契约写的，反过来塞进 V2 的 QTabWidget 要重写 6 个页面。 |
| D3 | **播放页/播放器换 V2 内核，但保留 V1 的公开契约** | V1 的 `vlc风格.py`（菜单/工具栏）、`AI播放面板.py`、`播放清单.py`、`全屏助手.py`、`截图提示.py` 都是**不认识 libvlc 的纯控件**，只有 `播放核心/播放出口/vlc绑定/游离窗口/窗口就绪` 是 VLC 专有。保留契约 → 这些控件与 AI 模块零改动即可复用。 |
| D4 | **`适配器/` 与 `运行环境/{本地模型,语音识别}` 一并并入** | 网盘管理功能与"AI 生成字幕/本地模型"依赖它们；`配置.解析路径()` 认 `适配器/<名>` 写法，放进去即被找到。 |
| D5 | **V1 的第三方依赖装进 V2 的 venv** | 合并后单环境；`启动.py` 只自举一次，桥子进程也用同一解释器。 |
| D6 | **VLC 播放栈整体删除，不做兼容垫片** | 需求明确"播放器用 V2 的"。保留 VLC 只会让"画面游离/句柄/输出模块"那些坑回来。 |
| D7 | **V2 的 `主窗口` 保留为 `--纯播放` 次要入口** | 617 条测试与 `工具/` 脚本都依赖它；保留可让"内核"始终有一条独立的、不依赖 V1 的回归路径。 |
| D8 | **`tests/test_独立性.py` 改判据** | 原判据"禁止出现 v8_3/禁止第三方依赖"是 V2 早期"完全独立"路线下的约定，现在用户要求整合，必须改。新判据改为：**播放内核不许调用 ffmpeg/ffprobe/vlc 命令行**、**`wangpan/player|ffmpeg|subtitle|danmaku` 不许 import `v8_3`**（内核仍独立）、**`wangpan/ui/主窗口.py` 不许 import `v8_3`**（纯内核壳仍独立）。 |

## 三、播放整合的接口契约（V1 公开面 → V2 内核）

V1 界面只认这几个东西（见 `02_V1界面架构.md` §4.2），合并后由
`wangpan/ui/播放会话.py` 提供：

* **会话方法**：`准备/起播/暂停/跳转/设置音量/设置速率/挂字幕/切换字幕/截图/状态快照/流畅优先/
  规则诊断/采样并诊断/应用新参数/安全回退画面/关闭/装主线程泵/排空主线程队列/取适配器`
* **会话属性**：`播放器/设置/媒体/探测/直链信息/网盘标识/远端路径/标题/出口/自动调优/AI决策状态`
* **`状态快照()` 键**：`状态/进度秒/时长秒/缓冲中/丢帧/丢帧增量/输入码率bps/已播秒/已解码视频/音量/倍速/…`
* **状态字符串**（8 个，写死）：`空闲/打开中/缓冲中/播放中/已暂停/已停止/已结束/出错`
* **`播放器` 门面**：`进度秒/时长秒/状态/设置缩放/缩放/设置宽高比/宽高比/停止并等待/绑定窗口/
  下一帧/字幕轨/音频轨/选择字幕/选择音频/当前字幕/章节数/当前章节/跳章节/下一章/上一章/
  取速率/设置速率/取音量/设置音量/是否静音/设置静音`

**整合优化点（有意偏离 V1 的地方）**：

1. **画面出口不再需要句柄**：V2 由 `视频控件` 自绘 → `起播(句柄)` 的 `句柄` 参数保留但忽略；
   `播放出口/游离窗口/窗口就绪/游离窗口守护` 全部删除，"画面游离"结构性消失。
2. **主线程泵变成直通**：V2 引擎允许任意线程调控制方法（内部有锁），
   `装主线程泵/排空主线程队列` 保留为空实现，`采样并诊断→应用新参数` 不再有 SEGV 风险。
3. **AI 参数语义重映射**：V1 的 `播放设置.附加选项/网络缓存毫秒` 是 libvlc 选项；
   V2 侧映射为 **读缓冲水位 / 硬解开关 / 起播等待**，`附加选项` 保留字段但内核忽略。
4. **独立窗口共享会话**：两个页面各自 16ms 取帧，不需要 V1 的"交接仪式"。
5. **弹幕/字幕层**：由 V2 的 `视频控件` 在同一次 `paintEvent` 里绘制（字幕+弹幕），
   天然不会跑到别的窗口。

## 四、分阶段落地（每阶段结束都能跑、都能测）

| 阶段 | 内容 | 验收 |
|---|---|---|
| **S1 并入与打通** | `v8_3/`、`适配器/`、`运行环境/{本地模型,语音识别}`、`配置.json`、用户数据并入；V1 依赖装进 V2 venv；`启动.py` 能起 V1 主窗口 | 离屏构造主窗口成功、7 个页面建出来 |
| **S2 播放内核适配** | 新增 `wangpan/ui/播放会话.py`（V2→V1 契约）+ `wangpan/ui/播放页.py`（从 V2 主窗口抽出）；V2 主窗口改用它 | V2 原有 617 条测试仍绿 |
| **S3 播放页替换** | 重写 `v8_3/界面/播放页面.py`、`播放器窗口.py`；删除 VLC 栈；主窗口接线 | 主窗口能切到播放页；本地文件真播（离屏截图有画面） |

| **S7 测试与真机** | 改 `test_独立性`；补整合测试；离屏真机验收（各页截图、真播、弹幕、刮削） | 全量测试绿 + 验收截图落盘 |
