# 网盘管理 2.1.0（整合版）

**一个程序 = V1 的界面与网盘管理能力 + V2 的自研播放内核。**

这一版不是功能叠加，而是把两个项目**合成一个**：界面、网盘管理、AI 全部沿用
V1（`v8_3/`），**播放页与播放器换成 V2 的自研 libav 内核**（`wangpan/`），
并把 VLC 那一整套彻底删掉。

---

## 这一版做了什么

### 1. 播放内核换血：VLC → 自研 libav\*

* **删掉约 3000 行** VLC 专用代码：`vlc绑定` / `播放核心` / `播放出口` /
  `显示环境` / `游离窗口` / `窗口就绪` / `游离窗口守护` / `播放控件`；
* **画面由 Qt 控件自绘**（帧 → QImage → 控件），字幕与弹幕在**同一次 paintEvent** 里叠加 ——
  "视频跑到别的窗口里播放""切页黑屏""退出崩在 VLC 线程上"这一类问题**结构上不再可能**；
* 硬解 VAAPI / D3D11VA，失败自动回退软解（本机 4K60 实测硬解 ≈0.9 核）；
* 新写 `wangpan/ui/播放会话.py` 作为适配层，把内核包装成界面与 AI 都认的接口
  （**21 个 `状态快照()` 键**、**8 个中文状态串**、播放器门面 25 个方法，全部按老契约复刻）。

### 2. 界面 / 网盘管理 / AI 全部沿用 V1

* 顶栏网盘导航 + 左侧功能栏 + 10 套主题的 GUI、三家网盘适配器与子进程桥、
  传输引擎（可调并发/退避/SQLite 任务库/断点续传/失败兜底/磁盘预算）、
  敏感词上传守卫（AC 自动机 + 预检改名 + 学习闭环）；
* AI 全套：智能助手（9 家 OpenAI 兼容网关 + 本地 ollama + 规则三级降级）、
  传输调度、字幕助手、播放顾问（含学习库）、本地模型与模型商店、
  语音识别、价格抓取、时段预算；
* V2 的**海报墙 / 详情页 / TMDB 刮削 / 待确认队列**包成 `媒体库` 页接进左侧第 3 项。

### 3. 整合时顺手做的事

* **AI 播放顾问接上新内核**：`网络缓存毫秒` 换算成 libavformat 读缓冲字节、
  `硬解` 映射成每路开关；并给顾问补上它一直缺的"缓冲中"信号（用播放时钟是否推进推断）；
* **独立窗口不再复制播放器**：把同一个播放页 `setParent()` 搬过去，同一会话、同一弹幕控制器；
* **补上 AI 常驻子进程的收尾**：`ollama serve` 原来被拉起后全项目没人停、
  Whisper 工作进程的 `卸载()` 全文没有调用点、`AI运行时.关闭()` 只关学习库 —— 现在退出时一起收；
* **修掉既有缺陷**：命令行/文件管理器给的视频被丢掉、窗口标题还是 V1 的旧串、
  `主窗口.保存配置()` 根本不存在（异常被吞）、启动横幅永远报 KeyError、主题样式安装顺序；
* **补快捷键**：`Ctrl+1..8` 翻页、`Ctrl+Q` 退出；窗口标题跟随当前页与正在播的片名。

## 怎么用（Linux 绿色版）

1. 解压到**任意目录**；
2. 双击 `一键启动_网盘管理_V2.sh`，或终端里 `./启动.sh`；
3. 想直接开播某个视频：`./启动.sh 某个视频.mp4`。

不需要装 Python（包内自带独立解释器）、不需要装依赖、不写系统目录。
**整个文件夹可以随意搬移**：里面的 venv 是从包内自带解释器重建的，符号链接是相对的。

第一次要自己做的三件事、以及没随包带的东西（AI 语音模型、ollama 模型权重），
见包内 `使用说明.txt`。

### 快捷操作

| 按键 | 作用 |
|---|---|
| `Ctrl+1..8` | 网盘 / 传输 / 播放 / 媒体库 / 敏感词 / AI / 日志 / 设置 |
| `Ctrl+Q` | 退出（走完整收尾） |
| `空格` `←` `→` `.` `[` `]` `PgUp` `PgDn` `F` `Esc` | 播放暂停 / 跳转 / 逐帧 / 调速 / 上下集 / 全屏 |

## 已知限制

* **多音轨切换**未做：内核目前只播第一条音轨（菜单里如实说"没有这个能力"，不假装成功）；
* **缩放/宽高比**只记账不改变形（画面永远保持源比例，这是不变形的唯一正解）；
* 媒体元数据用 `ffprobe` 读（给 AI 顾问用）；**播放内核本身完全不调外部命令**；
* 一键更新已停用（上游发的还是旧版 VLC 包，覆盖会把整合成果换掉）；
* 原生 Wayland 下**外部工具无法激活窗口**，所以真机自动化的交互部分依赖 X11/XWayland
  （同一份二进制、同一批代码路径，只是 Qt 平台插件不同）。

## 解压说明

```bash
# 推荐（Linux 自带）：
unzip wangpan-manager-2.1.0-Linux.zip -d 网盘管理
cd 网盘管理 && ./一键启动_网盘管理_V2.sh

# 用 7z 也可以：
7z x wangpan-manager-2.1.0-Linux.zip -o网盘管理
```

⚠️ **用 `7z x` 解压时会看到两条 `Dangerous link path was ignored` 警告** ——
那是 7z 的安全策略（拒绝创建"指向目录之外"的符号链接），
指的是 `运行环境/venv/bin/python3.14 -> ../../python/bin/python3.14` 这个解释器链接。
**不影响使用**：启动脚本会在启动前按实际位置把它补回来（幂等，几毫秒）。
（`tar` / `unzip` 一般会原样还原，那就更省事。）
